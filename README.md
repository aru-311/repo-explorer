# Repo Explorer

A React application for browsing GitHub repositories, viewing their details, and managing a list of favorite repositories.

## Features

- View a list of popular GitHub repositories.
- Search for specific repositories.
- View detailed information about a repository, including its README file, commit history, and other metrics.
- Add and remove repositories from a "Favorites" list.
- Responsive design for use on different devices.

## Tech Stack

- **React:** A JavaScript library for building user interfaces.
- **Redux Toolkit:** For predictable state management.
- **React Router:** For declarative routing in the application.
- **Ant Design:** A React UI library with a set of high-quality components.
- **Axios:** A promise-based HTTP client for making requests to the GitHub API.
- **Chart.js:** For creating charts and visualizations of repository data.
- **React Icons:** A collection of popular icon libraries.
- **React Loader Spinner & React Loading Skeleton:** For providing visual feedback during loading states.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/your_username/repo-explorer.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```

### Running the Application

To run the app in development mode:

```sh
npm start
```

Open [https://gitrepo-explorer.netlify.app/](https://gitrepo-explorer.netlify.app/) to view it in your browser. The page will reload when you make changes.
